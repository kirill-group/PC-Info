# PC Info

**PC Info** is a simple, lightweight console utility by **KIRILL GROUP** for displaying hardware and system information. Built for maximum compatibility across older and modern Windows versions.

## Features
- **OS Info:** Windows version, architecture, system folder, and uptime.
- **Hardware:** CPU, motherboard, total RAM, GPU, and physical drives.
- **Network:** Hostname and local IP address.
- **High Compatibility:** Runs on legacy .NET Framework versions out of the box.

## Tech Stack
- **Language:** C#
- **Framework:** .NET Framework (`System.Management` / WMI)
- **Dependency:** `OldKEngine`
